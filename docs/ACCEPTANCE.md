# 独立 App 人工验收

候选版本 0.16.4；自动检查不能代替下列人工验收。先退出共享默认数据目录的旧实例；建议用独立 `--user-data-dir`，确认资料均可用于对应服务后再主动调用。

- 从完整便携目录独立启动，无 Node、原项目或网页服务依赖。
- 胶囊、玻璃菜单、拖动、反馈动效、托盘、四个阅读页面和最小化/最大化/恢复符合原行为。
- 右键外观调参，预览材质/动效、恢复预设、分别保存、退出重启确认恢复；核对显示器、缩放、GPU 实际效果。
- 分别添加分析、ASR 配置；选择、删除、加密保存、重启恢复。迁移旧数据前自行备份，核对 v1/v2 保留与 v3 生效。
- 主动测试非百炼云端与本地视觉服务；确认 URL 前缀、模型 ID、鉴权与图片支持。测试失败、取消和修正后重试提示正确。
- 用合成或明确可上传资料，完成真实麦克风→ASR 最终转写→开始/结束两张截图→分析→历史；连续下一轮核对唯一会话、资料复用和归档。
- 核对本轮详情、数学公式、历史录音回放、截图、单条删除与确认全部清除。
- 录音/ASR/分析错误时检查提示和适用的主动重试；隐藏、切换页面不误结束学习；退出释放资源。
- 在实际多屏/缩放/窗口遮挡条件下核对学习截图与玻璃背景；胶囊和菜单强制排除，其他窗口跟随设置。整屏黑块仍是已知限制。

记录实际平台、硬件、服务及版本、通过/失败/未测。不要填写密钥或提交真实学习材料。只有用户确认后才将对应项标为验收通过。
